# ⚡ LightWidget — Мониторинг отключений света (macOS & iPhone)

Стильный виджет с темным Glassmorphism-интерфейсом для отслеживания времени отключения и восстановления электроэнергии на базе сообщений от Telegram-бота ДТЭК.

---

## 🚀 Возможности
- **Монитор реального времени**:
  - Живой статус питания (🟢 СВІТЛО Є / 🔴 ВІДКЛЮЧЕННЯ СВІТЛА).
  - Таймер обратного отсчета до ориентировочного восстановления (`ЧЧ:ММ:СС`).
  - Анимированная шкала прогресса времени отключения.
  - Детали: адрес, причина работ, точные таймстемпы начала и завершения.
- **Интеграция с iPhone (Scriptable)**:
  - Автоматическая раздача локального JSON API (`http://<IP_MAC>:8088/api/status`).
  - Готовый JavaScript-код для создания нативного виджета на домашнем экране или экране блокировки iOS.
- **Тестовый симулятор**:
  - Возможность мгновенно протестировать любые сообщения бота ДТЭК, задержки или восстановление питания в 1 клик.
- **Telegram Listener (Telethon)**:
  - Фоновое получение сообщений от бота без необходимости ручной пересылки.
  - Фильтрация по конкретной улице / номеру дома.
- **Системные уведомления macOS**:
  - Звуковые и визуальные баннеры при фиксации отключения или включения света.

## 📱 Настройка на iPhone

1. Установите бесплатное приложение **Scriptable** из App Store на iPhone.
2. В приложении LightWidget на Mac перейдите во вкладку **"iPhone Виджет"** и нажмите **"Скопировать код виджета"**.
3. В приложении Scriptable на iPhone создайте новый скрипт (+), вставьте скопированный код и сохраните.
4. Добавьте виджет Scriptable на экран "Домой" или экран блокировки.
