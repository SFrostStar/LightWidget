# ⚡ LightWidget — Мониторинг отключений света (macOS, Windows & iPhone)

Стильный виджет с темным Glassmorphism-интерфейсом для отслеживания времени отключения и восстановления электроэнергии на базе сообщений от Telegram-бота ДТЭК.

---

## 💻 Запуск на Mac / ПК

```
Установите программу из Release
Перенесите программу в папку Applications
Откройте терминал и напишите "xattr -cr /Applications/LightWidget.app"
Откройте программу
```
Либо:
```bash
cd LightWidget
python3 app.py
```

---

## 📱 Настройка на iPhone

1. Установите бесплатное приложение **Scriptable** из App Store на iPhone.
2. В приложении LightWidget перейдите во вкладку **"Виджет"** и нажмите **"Скопировать код виджета"**.
3. В приложении Scriptable на iPhone создайте новый скрипт (+), вставьте скопированный код и сохраните.
4. Добавьте виджет Scriptable на экран "Домой" или экран блокировки.
