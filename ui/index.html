Айфон виджет

            
Пошаговая инструкция по настройке виджета на iPhone через приложение Scriptable.

          


          

            

              
1

              

                Установи Scriptable
                Скачай бесплатное приложение Scriptable из App Store на свой iPhone.
              

            


            

              
2

              

                Создай скрипт виджета
                Открой Scriptable, нажми + в правом верхнем углу, вставь код ниже и сохрани с именем LightWidget.
              

            


            

              
3

              

                Добавь виджет на экран
                Зажми экран iPhone, нажми +, найди Scriptable, выбери размер виджета и укажи скрипт LightWidget.
